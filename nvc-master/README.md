# NVC Master 🦒

בוט טלגרם אישי שהוא מומחה לתקשורת מקרבת (NVC). אפשר להתכתב איתו, לשתף התלבטויות, ריבים והודעות שקשה לנסח, והוא עונה כמו מנחה בכיר: אמפתיה קודם, ואז ניסוחים שנשמעים כמו בן אדם.

הבוט מבוסס על Claude (מודל `claude-opus-5`) וטוען את סקיל `nvc-expert` המלא (בתיקיית `skill/`) כהנחיות המערכת שלו.

## מה צריך כדי להפעיל

1. **טוקן של בוט טלגרם**: פותחים בטלגרם את [@BotFather](https://t.me/BotFather), שולחים `/newbot`, נותנים שם, ומקבלים טוקן.
2. **מפתח API של Anthropic**: יוצרים בכתובת [console.anthropic.com](https://console.anthropic.com) תחת API Keys. שימו לב: השימוש ב-API מחויב בנפרד ממנוי Claude.

## הרצה מקומית

```bash
cd nvc-master
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # ולמלא את הטוקן והמפתח
python bot.py
```

מרגע שהבוט רץ, פותחים את הבוט בטלגרם ושולחים לו `/start`.

## הרצה בענן (כדי שהבוט יהיה זמין תמיד)

הבוט עובד ב-long polling, אז כל שרת קטן מספיק, בלי דומיין ובלי webhook. אפשרויות נוחות:

- **Railway / Render / Fly.io**: מחברים את הריפו, מגדירים את משתני הסביבה מ-`.env.example`, וה-`Dockerfile` שבתיקייה עושה את השאר.
- **שרת פרטי / Raspberry Pi**: פשוט להריץ `python bot.py` (למשל תחת `tmux` או שירות systemd).

## הגדרות (משתני סביבה)

| משתנה | חובה | הסבר |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | כן | הטוקן מ-BotFather |
| `ANTHROPIC_API_KEY` | כן | מפתח ה-API של Anthropic |
| `TELEGRAM_ALLOWED_USER_IDS` | לא | הגבלת הבוט למשתמשים מסוימים (מזהים מספריים, מופרדים בפסיק). מומלץ! בלי זה כל מי שמוצא את הבוט יכול לדבר איתו על חשבונך |
| `CLAUDE_MODEL` | לא | ברירת מחדל `claude-opus-5` |
| `MAX_HISTORY_MESSAGES` | לא | כמה הודעות אחרונות נשמרות בזיכרון השיחה (ברירת מחדל 60) |

## פקודות בבוט

- `/start` — פתיחה
- `/reset` — מתחיל שיחה נקייה (שוכח את ההיסטוריה של הצ'אט)

## איך זה עובד

- `bot.py` מאזין להודעות בטלגרם ושולח אותן ל-Claude יחד עם היסטוריית השיחה של אותו צ'אט.
- ההנחיות של המומחה נטענות מ-`skill/SKILL.md` ושלושת קבצי העזר (רגשות וצרכים, תהליכי עומק, דוגמאות עבודה) — אותו סקיל בדיוק שרץ אצלך ב-Claude.
- היסטוריית השיחות נשמרת בקובץ `histories.json` מקומי (לא נכנס לגיט), עם `cache_control` על ה-system prompt כדי לחסוך בעלויות.
- אם בקשה נדחית מטעמי בטיחות, מופעל מנגנון fallback אוטומטי של ה-API (`fallbacks: "default"`).
