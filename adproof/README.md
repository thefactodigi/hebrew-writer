# AdProof — כלי הדמיה ואישור התאמות קמפיין

כלי ווב פנימי למעצב/סוכנות: גוררים את כל קבצי ההתאמות של קמפיין (JPG/PNG/GIF),
הכלי מזהה מידות, משייך אוטומטית לפלייסמנטים בכל הפלטפורמות (Google Display,
Performance Max, Meta, Yandex), מציג מסך סקירה בפרופורציות אמת — ומייצא PDF
ממותג לאישור לקוח. הכל רץ בדפדפן, בלי backend.

## הרצה

```bash
npm install
npm run dev        # פיתוח
npm run build      # בילד סטטי ל-dist/
npm run build:single  # קובץ HTML יחיד שנפתח בלחיצה כפולה (dist-single/)
npm test           # בדיקות מנוע השיוך
```

## פריסה ב-Vercel (עדכון אוטומטי בכל push)

חיבור חד-פעמי: ב-vercel.com → Add New → Project → מייבאים את הריפו
`thefactodigi/hebrew-writer` → מגדירים **Root Directory: `adproof`** →
Deploy. השאר (Vite, פקודת בילד, תיקיית פלט) מזוהה מ-`vercel.json`.
מאותו רגע כל push ל-branch הפרודקשן מתפרסם אוטומטית, וכל branch אחר
מקבל Preview URL משלו.

## מבנה

```
src/
  specs/specs.ts      ← ספריית המפרטים — כל המידות והפלייסמנטים בקובץ אחד.
                        הוספת מידה חדשה = רשומה אחת, בלי לגעת בלוגיקה.
  engine/matcher.ts   ← מנוע השיוך (טהור, עם בדיקות): exact, רטינה x2/x3,
                        יחס עם טולרנס 1%, ריבוי שיוכים בין פלטפורמות.
  engine/validators.ts← אזהרות משקל/פורמט/רזולוציה (מצב עבודה בלבד).
  engine/fileIntake.ts← קריאת מידות אמיתיות מהקובץ, זיהוי GIF מונפש.
  engine/scale.ts     ← קנה מידה חכם לתצוגה (צד קצר ≥ 140px וכו').
  store/session.ts    ← Zustand + שמירת סשן מלאה (כולל הקבצים) ל-IndexedDB.
  store/derive.ts     ← גזירת מבנה התצוגה: פלטפורמות/קבוצות/לא-משויך/מה-חסר.
  components/         ← UploadZone, ReviewBoard, PlatformSection, CreativeCard,
                        Lightbox, MissingPanel, MockupFrame, UnassignedZone
  pdf/exporter.ts     ← ייצוא PDF עם pdf-lib: שער, עמודי פלטפורמות, הטמעת
                        תמונות ברזולוציית מקור, פונט Heebo מוטמע, פוטר.
  pdf/bidi.ts         ← סידור ריצות כיווניות לטקסט עברי/מעורב ב-PDF.
```

## עקרונות מרכזיים

- **מה שיש מוצג, מה שאין נעלם**: פלטפורמה/קבוצה/סלוט בלי קובץ לא מופיעים
  בתצוגה וב-PDF. פאנל "מה חסר" (למעצב בלבד) מפרט מה לא הועלה.
- **פרופורציות אמת תמיד**, חדות מלאה, תמיכת רטינה (@2x/@3x מוצג בגודל הסלוט).
- קובץ אחד יכול להשתייך לכמה פלטפורמות במקביל (300×250 → GDN + Yandex).
- כפילויות באותה מידה מקבלות תגי "גרסה A / גרסה B", בלי דריסה שקטה.
- תיקון שיוך בגרירה בין קבוצות, הסתרה בכפתור עין, סדר קבוצות נשמר ל-PDF.
- ב-PDF: GIF נלכד כפריים ראשון עם תג "Animated GIF"; אם המסמך חורג מ-25MB,
  התמונות הגדולות בלבד נדחסות ל-JPEG באיכות 85.
